# 🌱 Sprout Scouts: An EcoQuest Adventure

A mobile gamified learning app designed to make education 
fun and engaging for children through interactive gameplay.

## About

An eco-themed educational app designed to make learning 
fun and interactive for kids through quests, challenges, 
and adventures. Featuring a structured game flow — habitat 
selection, drag-and-drop puzzles, and animated reward 
sequences with characters that respond dynamically to 
player answers.

## Built With

- React Native
- Expo
- TypeScript

## Features

- Drag-and-drop puzzle mechanics
- Interactive animated character feedback
- Multi-habitat navigation
- Animated reward sequences
- Custom audio management system
- Video backgrounds and screen transitions

## Getting Started

1. Install dependencies
```bash
   npm install
```

2. Start the app
```bash
   npx expo start
```
